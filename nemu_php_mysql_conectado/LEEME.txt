Para la instalacion

## 1. Dónde poner la carpeta

Copia la carpeta `nemu_php_mysql_conectado` dentro de:

```txt
C:\xampp\htdocs\
```

La ruta final debe quedar así:

```txt
C:\xampp\htdocs\nemu_php_mysql_conectado\
```

## 2. Importar la base de datos

1. Abre XAMPP.
2. Activa Apache y MySQL.
3. Entra a phpMyAdmin.
4. Ve a Importar.
5. Selecciona este archivo:

```txt
sql/base_de_datos_nemu_corregida.sql
```

6. Presiona Continuar.

## 3. Revisar conexión

El archivo de conexión está aquí:

```txt
config/conexion.php
```

Por defecto está configurado así:

```php
$host = "localhost";
$usuario = "root";
$password = "";
$base_datos = "nemu_";
```

## 4. Abrir el sistema

En el navegador abre:

```txt
http://localhost/nemu_php_mysql_conectado/
```
