El sistema manejará rol de maestro y rol de alumno.

Los maestros podrán administrar cursos, asignar alumnos, gestionar inscripciones y visualizar la información académica dentro de la plataforma.

El sistema Nemu utiliza HTML, CSS, JavaScript y Bootstrap para el desarrollo del FrontEnd, permitiendo crear una interfaz moderna, responsiva e interactiva para los usuarios. Además, el sistema estará conectado a una base de datos MySQL para el almacenamiento y administración de información como usuarios, cursos e inscripciones. También se implementará JavaScript para manejar funciones dinámicas y posteriormente integrar las operaciones CRUD (crear, consultar, actualizar y eliminar registros) dentro del sistema.
